SELENA BIRTHDAY WEBSITE — V2

Open index.html normally for the birthday experience.
PIN: 1225

PRIVATE EDIT MODE
Open the site with ?edit=1 at the end of the URL.
Example: index.html?edit=1
A Customize button will appear at the bottom-right.

You can:
- Upload up to 8 memory photos
- Upload your own audio file for “I Love You 3000”
- Preview / pause music
- Clear uploaded photos or music

Important: the upload editor saves files locally in that browser/device using IndexedDB. This is intended for easy editing/testing. Before public deployment, place the final images/audio into the website files so every visitor sees/hears them.
